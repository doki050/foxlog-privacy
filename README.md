# FoxLog static site

Public landing, privacy and support site for FoxLog.

## Pages

- `index.html` — product landing page (HU/EN)
- `privacy.html` — privacy policy (HU/EN)
- `support.html` — support and FAQ (HU/EN)

The site is intentionally dependency-free and suitable for GitHub Pages. It does not use analytics, cookies, third-party fonts, or external JavaScript.

FoxLog is shown as **Coming soon to the App Store** until a public App Store URL is available.
